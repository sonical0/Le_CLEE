Test Bannière d'Accessibilité

Cette page permet de tester la bannière d'accessibilité qui s'affiche au lancement du site CLEE Bordeaux Avenir.

État actuel

Bannière fermée: Non
Contraste élevé: Non
Thème: Étudiant

Actions de test

Instructions de test

  1. Cliquez sur "Réinitialiser localStorage" pour supprimer toutes les préférences
  2. Cliquez sur "Ouvrir le site CLEE" pour charger la page d'accueil
  3. Attendez 1 seconde → la bannière doit apparaître en bas de l'écran
  4. Testez les trois actions :
    • Activer : Active le contraste et ferme la bannière
    • Non merci : Ferme la bannière sans activer
    • X : Idem que "Non merci"
  5. Rechargez la page → la bannière ne doit plus apparaître
  6. Allez sur pages/portail.html pour modifier les options manuellement
