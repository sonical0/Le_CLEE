Comment utiliser les thèmes ?

Pour l'utilisateur final :

  1. Accédez à la page portail.html
  2. Choisissez votre profil : Étudiant ou Professionnel
  3. Le thème correspondant s'applique automatiquement sur toutes les pages
  4. Cliquez sur le badge flottant pour changer de profil

Différences visuelles :

  • Mode Professionnel : Design sobre, tons bleus/gris, aspect corporate
  • Mode Étudiant : Couleurs vives (orange, cyan, vert, rouge), dégradés, animations dynamiques
