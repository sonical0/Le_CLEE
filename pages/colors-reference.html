Usage du thème Professionnel

                
    
                    
  • Bleu Foncé (#1F3448) : Titres, navigation, footer
    • 
                    
  • Bleu Moyen (#5E7E9F) : Liens, boutons, accents
    •

Dégradés Utilisés

            
            

                

                    Dégradé Primaire

                    Orange → Jaune
                

                
                

                    Dégradé Secondaire

                    Cyan → Vert
                

                
                

                    Dégradé Hero

                    Orange → Jaune → Cyan
                

            

            
            

                
Usage du thème Étudiant

                
    
                    
  • Orange (#FF6B35) : Boutons principaux, liens, CTA, accents
    • 
                    
  • Cyan (#00A7E1) : Liens secondaires, badges, icônes
    • 
                    
  • Vert (#5CB85C) : Validation, succès, chiffres clés
    • 
                    
  • Rouge (#E74C3C) : Alertes, urgence, chiffres clés
    • 
                    
  • Dégradés : Hero section, boutons, titres, effets
    • 
                

            

        

        
        

            
Comparaison Rapide

            
            

                
                    

                        Élément
                        Thème Professionnel
                        Thème Étudiant
                    

                
                
                    

                        Boutons
                        Bleu uni
                        Dégradé orange/jaune
                    

                    

                        Titres
                        Bleu foncé
                        Dégradé coloré
                    

                    

                        Hero
                        Dégradé bleu sobre
                        Dégradé orange/cyan + effets
                    

                    

                        Chiffres clés
                        Couleur uniforme
                        Chaque chiffre coloré différemment
                    

                    

                        Badge
                        Aucun
                        Badge flottant "Mode Étudiant"
